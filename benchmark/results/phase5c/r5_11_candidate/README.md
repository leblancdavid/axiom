# R5.11 distinct B01 candidate

`task_manager.py` and `provenance.json` are generated by
`benchmark.semantic.b01_integration_r5_11.build` from the R5.11 template and
contract. They are **prospective integration artifacts**, not the historical
checkpoint-pinned B01 executable, the canonical `generated/` backend output,
or an amendment to R5.2.2. Regenerate with:

```powershell
python -c "from benchmark.semantic.b01_integration_r5_11 import build; build('benchmark/results/phase5c/r5_11_candidate')"
```

The CLI works without instrumentation environment variables; independent
capture supplies a trace path and invocation ID for selected subprocess runs.
