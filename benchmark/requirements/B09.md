# B09 — Due window (cross-cutting)

Add `list-due --start UTC_TIMESTAMP --end UTC_TIMESTAMP`. Include only
nonarchived pending tasks with a due date in the **inclusive** interval
`[start, end]`, ordered normally. Equal endpoints are valid; start after end
fails `invalid_window`. Invalid/non-UTC timestamps fail `invalid_due_date`.
Undated or completed tasks are excluded and the query has no write effect.
