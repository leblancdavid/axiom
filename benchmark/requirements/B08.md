# B08 — Archival (cross-cutting)

Tasks gain an `archived` boolean, default false (also for migrated tasks),
independent of pending/completed status. `archive --id ID` sets true and
returns the task; repeating it fails `invalid_transition`. Archived tasks are
hidden from `list`, `list-high`, `list-overdue`, `list-tag`, `list-status`, and
`list-category`. Add `list-archived` to expose them in normal order. Archiving
either pending or completed tasks is valid; the status value does not change.
