# B18 — Audit history (architectural)

Record each successful task mutation (`create`, `complete`, `delete`, `archive`,
`append-note`, `add-dependency`) once with monotonic sequence number, UTC
timestamp, actor ID, operation name and task ID. `list-audit` returns entries
in sequence order. Rejected operations add no entry; task mutation and its
entry succeed or fail together. Migrating existing storage starts an empty
history; user creation is not a task mutation.
