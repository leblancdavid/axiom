# B06 — Categories (cross-cutting)

Add `create --category VALUE`, default `""`, returned on all tasks. A supplied
nonempty value is trimmed; whitespace-only input fails `invalid_category`.
Omission, an explicitly empty value, and migrated tasks use `""`. Add
`list-category --category VALUE` for exact, case-sensitive matching, including
`""` to select uncategorized tasks. Standard list retains all tasks.
