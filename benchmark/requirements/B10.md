# B10 — Optional owner (cross-cutting)

Add `create --owner USER_ID` and a returned `owner` string. Omitted owner and
migrated tasks have `""`. A supplied owner is trimmed and must be nonblank;
otherwise fail `invalid_owner`. Add `list-owner --owner USER_ID` for exact,
case-sensitive matches (including `""` for unowned). This step does not yet
require that an owner correspond to a user.
