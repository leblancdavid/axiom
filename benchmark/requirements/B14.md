# B14 — Dependencies (invariant)

Each task gains an ordered `dependencies` array of task IDs, initially `[]`
(also on migrated tasks). `add-dependency --id ID --depends-on OTHER_ID`
appends OTHER_ID and returns the updated task. Reject self-references with
`invalid_dependency`, nonexistent OTHER_ID with `task_not_found`, duplicates
and cycles with `invalid_dependency`. A failure leaves both tasks unchanged.
Existing dependencies refer to IDs, including archived tasks. Deleting a task
still referenced by another task fails `dependency_in_use` without changes.
