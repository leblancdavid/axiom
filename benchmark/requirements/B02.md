# B02 — Task tags (local)

Accept zero or more `--tag VALUE` flags on `create`. Each VALUE must be a
nonblank string after trimming whitespace; store the trimmed value. Tags are
case-sensitive, deduplicated while retaining first occurrence order, and
returned as a `tags` array on every task. Omission and migrated older tasks
have `tags: []`. Empty tag input fails `invalid_tag` with no new task.
